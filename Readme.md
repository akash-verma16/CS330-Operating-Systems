# Operating Systems Lab (CS330-2025)

1. This repository documents my work for the Operating Systems Lab course (2025) instructed by **Prof. Debadatta Mishra**. The exercises implement core OS mechanisms including system calls, virtual memory management, round-robin scheduling, and copy-on-write fork primarily within the gemOS environment. 
2. Each lab folder contains the original PDF problem statement, a `README` with brief problem descriptions, and the `submission` folder containing my code.
3. Please note that **Labs 3, 8, and 10** were conducted as in-lab examinations; therefore, their problem statements and submissions are not included in this collection.
